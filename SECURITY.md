# Security and sensitive data

This package is research software, not a clinical decision system or a secure data-processing service. Run it only on inputs you are authorized to use. Identity tokens are not anonymization; hashes do not authenticate a person or manifest signer.

Do not report vulnerabilities with participant records, credentials, machine paths or private manifests in a public issue. Use the repository's private vulnerability-reporting facility if it is enabled; otherwise ask the corresponding author for a private reporting channel before sending sensitive details. No dedicated security mailbox or response-time commitment is currently established.

Never run untrusted notebooks or scripts merely because they accompany a manifest. Verification checks file consistency, not whether code is safe to execute. Keep sensitive data and licensed fonts outside public archives.
