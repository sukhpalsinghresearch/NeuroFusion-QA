# Data boundary

This repository intentionally contains no participant-level EEG, fMRI, genotype, quality-control, feature, prediction, or protected-cohort files.

The source PEARL-Neuro dataset is available from OpenNeuro as dataset `ds004796`, version 1.1.0, DOI `10.18112/openneuro.ds004796.v1.1.0`. Users must obtain the dataset from its authoritative host and comply with its terms.

Raw data and derived subject-level outputs are ignored by `.gitignore`. Keep protected manifests outside the repository and outside any path visible to development analysis code.
