# Notebook evidence artifacts

This directory contains compact, machine-readable outputs generated by the numbered S01 notebooks. The artifacts summarize synthetic/public software tests; they do not contain participant-level data or establish clinical validity.

- `00_preflight_report.json`: environment, boundary-validator result, protocol hash, and seed policy.
- `01_feature_contracts.json`: deterministic synthetic feature shapes, ordering hashes, and integrity pass/fail reports.
- `01_core_workflow.json`: QC boundary matrix, quality scaling, fusion diagnostics, nested modelling coverage, same-seed replay, dependency versions, and local source hashes.

Notebook 04 also exports `04_failure_matrix.csv` (open gaps retained), `04_performance_results.csv`, `04_robustness_results.csv`, `04_claim_evidence_ledger.csv`, `04_release_audit.json` and `SHA256SUMS.txt`. The audit reports submission readiness separately from passing code assertions. Checksums cover aggregate artifacts and figures only, exclude themselves and private fonts, and must be regenerated after artifact edits.

Expected artifacts and acceptance requirements are defined in `../NOTEBOOK_SPECIFICATION.md`. Raw NumPy arrays and participant-like data files are not permitted here.
